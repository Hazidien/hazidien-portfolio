# Hazidien Ramadhan Utomo — GIS Portfolio

Interactive CV + portfolio website for GIS, remote sensing, LiDAR, spatial modelling, WebGIS and GeoAI opportunities.

## Current structure
- `index.html` — portfolio homepage
- `style.css` — responsive visual system
- `script.js` — project filtering, modal details, mobile navigation and scroll reveal
- `assets/` — profile and project media

## GitHub Pages
Enable **Settings → Pages → Deploy from a branch → main → /(root)** in this repository.
